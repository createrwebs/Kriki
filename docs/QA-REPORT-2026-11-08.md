## จุดที่พบและแก้ระหว่าง QA

1. `EntityDefinition` เดิมกลับเงื่อนไข `array_is_list` ทำให้ canonical field map ที่ใช้ UUID เป็น key ถูกปฏิเสธ แก้แล้ว และ PHP 8 checks/JS 4 tests ผ่าน
2. `github-import-publish.php` ตรวจ `BinaryFileResponse::getContent()` ซึ่งว่างแม้ไฟล์ถูกเสิร์ฟจริง แก้ regression ให้ตรวจไฟล์จาก response object โดยตรง จากนั้น import → publish ผ่าน 8 checks
3. เพิ่ม regression แยกบัญชีสำหรับ plan, credit bonus, usage ledger และ quota consumption ยืนยันว่า Alice/Bob ไม่อ่านหรือใช้ยอดของกันและกัน
3. การรัน `npm` ผ่าน PowerShell ถูก execution policy บล็อกที่ `npm.ps1`; ใช้ `npm.cmd run build` ซึ่งเป็นคำสั่งเดียวกันและ build ผ่าน 17.28 วินาที
